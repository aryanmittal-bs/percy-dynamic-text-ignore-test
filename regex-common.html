Static control block. Identical on every load. A difference reported inside this block means the rule has over matched and is touching content it was never meant to.

Reference line: the quick brown fox jumps over the lazy dog, 0123456789. This block contains no value that matches the rule.

Background and all five styles are fixed. Add ?static=1 to the URL to stop the values randomising.
